# RETINA-AI

RETINA-AI is a research prototype for diabetic retinopathy screening and progression monitoring. The application provides:

- Patient registration and management
- Retinal image upload and preprocessing
- DR severity prediction in demo mode or with a real model
- Multi-visit progression tracking
- Explainability preview with a Grad-CAM-style visualization
- PDF report generation
- Persistent SQLite storage

## Demo mode and real model integration

This prototype intentionally starts in DEMO MODE when no trained model is found. The app is designed so a real model can be integrated later by placing a trained checkpoint in the `model/` directory and updating the classifier logic in the modular `modules/dr_classifier.py` file.

The app does not claim that the demo engine is a medically validated DR model. It labels outputs as demonstration predictions and reminds users that the system is for research and clinical decision-support only.

## Clinical usage disclaimer

This application is not a medical diagnosis system. It should be used as a research-oriented decision-support prototype and must be reviewed by a qualified eye-care professional.

## Model development pipeline

The `training/` folder contains example dataset-loading and training scaffolding using EfficientNet-B0 as the preferred architecture. It is structured for later integration with a real dataset such as the APTOS 2019 Blindness Detection dataset or another properly licensed retinal imaging dataset.

## Known limitations

- The default detection engine is a heuristic demo predictor, not a trained medical model.
- Grad-CAM images are illustrative in demo mode and are not generated by a real trained network.
- Real-world clinical deployment requires model validation, dataset review, and clinician oversight.
